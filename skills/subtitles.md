# Навык: субтитры (SRT)

- У каждого блока есть номер и тайминг — их не переводят и не меняют.
- На каждый id верни ровно один перевод — только текст реплики.
- Сохраняй количество строк внутри блока (перенос строки в JSON — «\n»): разбито на две
  строки — в переводе тоже две.
- Старайся держать строку в пределах ~40 символов. Если не хватает места, переноси часть
  на вторую строку, но не сокращай смысл. Блоки между собой не склеивай и не разбивай,
  порядок и тайминги не сдвигай.
- Служебные пометки ([музыка], звуки, имена говорящих в скобках, тексты песен) переводи,
  если они осмысленны; звукоподражания — русским аналогом.
- Не добавляй точку в конце короткой реплики, если её нет в оригинале. Вопросительные и
  восклицательные знаки сохраняй.
- Многоточие и обрыв реплики (…, —, --) сохраняй: это часть ритма речи.
- Имена персонажей переводи одинаково во всех блоках — сверяйся с глоссарием и с уже
  переведённым контекстом.
