# Навык: английский → русский

- Артикли a/the в русском не передаются; определённость выражай контекстом.
- Времена: Present Perfect → часто прошедшее совершенное; Past Perfect → предпрошедшее;
  Continuous → «процесс», если он важен по смыслу.
- Gerund / Infinitive: переводи глаголом или отглагольным существительным по контексту,
  не калькируй -ing.
- Phrasal verbs переводи по смыслу: give up → сдаться (не «отдать вверх»).
- Модальные: must / have to → должен; should → следует; may / might → возможно;
  will / going to → будущее время.
- «Ложные друзья переводчика»: actual ≠ актуальный, accurate ≠ аккуратный,
  sympathetic ≠ симпатичный, dramatic ≠ драматичный, personal ≠ персональный.
- Значение слова выбирай по контексту, а не первое из словаря.
- Имена и названия: устоявшийся русский вариант (London → Лондон, the Thames → Темза);
  имена людей — практическая транскрипция (Smith → Смит).
- Единицы измерения переводи словами (miles → мили), числа не пересчитывай без просьбы.
- Не копируй английскую «Заглавную Каждую Слову» в заголовках — по-русски пиши как обычно.
- Кавычки и тире — русские («», —).
